# 解析规则

## 1. 类型判断（type）

| 类型 | 触发条件 | 示例 |
|------|----------|------|
| **Action** | 默认类型，单次可执行任务 | "买牛奶"、"提交论文" |
| **Project** | 关键词：项目、完成xxx、xxx计划、包含多步骤、由多个任务组成 | "论文投稿项目"、"准备汇报" |
| **Habit** | 关键词：每天、每周、定期、习惯、坚持、例行 | "每天看一篇论文"、"每周运动" |

**判断优先级**：Habit > Project > Action

---

## 2. Area 判断

| Area | 触发关键词 |
|------|----------|
| 科研 | 论文、实验、文献、研究、学术、代码、项目、专利、课题 |
| 学习 | 课程、学习、考试、作业、看书、培训、网课 |
| 健康 | 健身、游泳、跑步、运动、体检、医院、吃药 |
| 党建 | 党员、会议、学习强国、党课、组织生活 |
| 生活 | 购物、家务、缴费、快递、约会、聚餐、生日 |

**默认值**：如果无法判断，根据任务内容推测，否则留空让用户指定。

## 3. 截止日期解析

### 相对时间

| 表达方式 | 解析规则 |
|----------|----------|
| 今天 | 当天 23:59 |
| 明天 | 次日 23:59 |
| 后天 | 后天 23:59 |
| 大后天 | 大后天 23:59 |
| 下周一 ~ 下周日 | 下周对应日期 23:59 |
| 这周五 / 本周五 | 本周五 23:59 |
| 周五前 | 本周五 23:59 |
| 下周 | 下周一 00:00 |
| 下个月 | 下月1日 00:00 |

### 绝对时间

| 表达方式 | 解析规则 |
|----------|----------|
| 3月25号 / 3月25日 | 当年 2026-03-25 23:59 |
| 3月25号下午3点 | 2026-03-25 15:00 |
| 25号 | 当月25号 23:59 |
| 下周三下午2点 | 下周三 14:00 |

### 具体时间点

| 表达方式 | 解析规则 |
|----------|----------|
| 上午 | 当天 09:00 或上下文推断 |
| 下午 | 当天 14:00 或上下文推断 |
| 晚上 | 当天 19:00 或上下文推断 |
| 下午3点 / 3pm | 当天或指定日期 15:00 |
| 晚上8点 | 当天或指定日期 20:00 |

### 特殊表达

| 表达方式 | 解析规则 |
|----------|----------|
| 尽快 / 越快越好 | 不设置截止日期，今日优先级设为 Critical |
| 这周内 | 本周日 23:59 |
| 月底 | 当月最后一天 23:59 |
| 年底 | 当年12月31日 23:59 |

## 4. 耗时解析

### 小时表达

| 表达方式 | 解析结果（分钟） |
|----------|------------------|
| 半小时 / 0.5小时 | 30 |

| 1.5小时 / 一个半小时 | 90 |
| 2小时 / 两个小时 | 120 |
| 2-3小时 | 150（取中间值） |

|----------|------------------|
| 一上午 / 半天 | 180 |
| 一天 | 480 |

| 一周 | 2400 |

|----------|------------------|

## 5. 项目关联解析

### 识别模式

| 表达方式 | 解析结果 |
|----------|----------|
| 属于xxx项目 | 所属项目 = xxx |
| 在xxx项目里 | 所属项目 = xxx |
| 归到xxx | 所属项目 = xxx |
| xxx项目的 | 所属项目 = xxx |

### 示例

- "这个属于论文投稿项目" → 所属项目 = 论文投稿
- "归到党建工作里" → 所属项目 = 党建工作

## 6. 今日优先级判断

| 条件 | 今日优先级 |
|------|----------|
| 截止日期是今天 | Critical |
| 截止日期是明天 | Progress |
| 用户说"紧急"/"重要"/"必须" | Critical |
| 用户说"今天要做" | Critical |
| 其他 | 无（默认） |

## 8. 解析优先级

当用户输入包含多个信息时，按以下优先级解析：

1. **任务名称**：必须提取
2. **截止日期**：时间表达优先
3. **类型**：关键词判断
4. **Area**：关键词匹配
5. **预计耗时**：时长表达
6. **所属项目**：关联表达
7. **今日优先级**：根据截止日期和关键词判断

## 9. Cron 提醒时间计算规则

**适用条件**：
- 任务类型 = Action
- 截止日期 已指定
- 用户未明确拒绝提醒

**提醒时间规则**：

| 截止时间距离当前时间 | 提醒提前量 |
|---------------------|-----------|
| > 24 小时 | 提前 30 分钟 |
| 1-24 小时 | 提前 15 分钟 |
| < 1 小时 | 提前 10 分钟 |

**计算方式**：
1. 获取当前时间戳（毫秒）
2. 计算时间差 = 截止时间戳 - 当前时间戳
3. 根据时间差选择提前量
4. 提醒时间戳 = 截止时间戳 - 提前量（毫秒）

**示例**：
- 明天 15:00 截止（>24h）→ 提前 30 分钟 → 明天 14:30 提醒
- 今天 19:00 截止（现在 11:00，8 小时后）→ 提前 15 分钟 → 今天 18:45 提醒
- 30 分钟后截止（<1h）→ 提前 10 分钟 → 20 分钟后提醒

**不创建提醒的情况**：
- 提醒时间已过（提醒时间戳 < 当前时间戳）
- 用户明确说"不要提醒"
- 任务类型是 Habit 或 Project
