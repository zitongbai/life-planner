# 个人日程数据表格创建技能

## 固定配置

| 配置项 | 值 |
|--------|-----|
| 文件夹名称 | 日程管理 |
| 表格名称（正式模式） | 个人日程数据 |
| 表格名称（测试模式） | 个人日程数据-测试 |

---

## 创建流程

### Step 0: 识别创建模式

判断用户意图：
- 用户说"测试"、"试一下"、"测试一下"等 → **测试模式**
- 其他情况 → **正式模式**

根据模式确定表格名称：
- 正式模式：个人日程数据
- 测试模式：个人日程数据-测试

---

### Step 1: 检查并创建文件夹

1. 调用 `feishu_drive_file.list` 列出云文档根目录
2. 查找是否存在 "日程管理" 文件夹
   - **存在** → 获取 folder_token
   - **不存在** → 调用 `feishu_drive_file` action=upload 创建文件夹（type=folder），获取 folder_token

---

### Step 2: 检查表格是否已存在

1. 调用 `feishu_drive_file.list` 列出该文件夹内容
2. 查找是否存在同名多维表格（根据 Step 0 确定的名称）
   - **不存在** → 直接进入 Step 3 创建
   - **存在** → 询问用户是否覆盖
     - 用户选择"覆盖" → 删除旧表格，进入 Step 3
     - 用户选择"取消" → 结束流程

---

### Step 3: 创建多维表格

调用 `feishu_bitable_app.create`：
- name: 根据 Step 0 确定的表格名称
- folder_token: Step 1 获取的值

返回：app_token, default_table_id, url

---

### Step 4: 创建字段

按以下顺序创建字段（详细定义见 [template.md](references/template.md)）：

**4.1 单选字段（4个）**
- 类型 (type=3): Action / Project / Habit
- 状态 (type=3): 待办 / 进行中 / 已完成 / 已取消
- 今日优先级 (type=3): Critical / Progress / Optional / 无
- Area (type=3): 科研 / 学习 / 健康 / 党建 / 生活

**4.2 日期字段（1个）**
- 截止日期 (type=5)

**4.3 数字字段（2个）**
- 预计耗时（分钟）(type=2)
- 实际耗时（分钟）(type=2)

**4.4 文本字段（1个）**
- 描述 (type=1)

**4.5 关联字段（1个）**
- 所属项目 (type=18): 自关联到本表，property.table_id 填入 default_table_id

**4.6 自动时间字段（2个）**
- 创建时间 (type=1001)
- 最后更新 (type=1002)

---

### Step 5: 创建视图

调用 `feishu_bitable_app_table_view.create`：

1. 全部任务 (view_type=grid)
2. 项目视图 (view_type=grid)
3. 习惯视图 (view_type=grid)
4. 按Area分组 (view_type=grid)

---

### Step 6: 自检与修复

1. 调用 `feishu_bitable_app_table_field.list` 获取字段列表
2. 调用 `feishu_bitable_app_table_view.list` 获取视图列表

**修复操作**：
- 重命名主字段：将默认的"文本"改为"任务名称"
- 删除默认字段：删除自带的单选、日期、附件字段
- 删除默认视图：删除自带的"表格"视图

**确认**：
- 字段数量：12个 ✓
- 视图数量：4个 ✓

---

### Step 7: 返回结果

```
✅ 创建成功！

📁 位置：云文档 / 日程管理 / {表格名称}
🔗 链接：https://xxx.feishu.cn/base/xxx

表格包含：
- 12 个字段
- 4 个视图

你现在可以开始添加任务了！
```

（{表格名称} 为 Step 0 确定的名称）

---

## 注意事项

1. **关联字段**：需要在获取 default_table_id 后才能创建，property.table_id 填入本表的 table_id
2. **默认表清理**：新创建的多维表格会自带默认字段和视图，需要删除
3. **主字段**：默认的主字段名为"文本"，需要重命名为"任务名称"

---

## 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 文件夹创建失败 | 提示用户检查权限，重试 |
| 表格创建失败 | 提示具体错误，建议重试 |
| 字段创建失败 | 记录已创建的字段，提示用户手动检查 |
| 关联字段创建失败 | 提示用户，但继续创建其他字段 |
